# Закрывающий тег

Проект Яндекс Практикума о первых четырёх спринтах курса вёрстки. На странице восемь карточек с пиксельными иллюстрациями, анимированными лайками и диалогом сохранения.

## Локальный запуск

В корне проекта запустите сервер. Он нужен в том числе для загрузки внешнего SVG-символа дискеты.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальную страницу](http://127.0.0.1:8000/).

## Публикация

После отправки ветки `main` в репозиторий GitHub выберите **Settings → Pages → Deploy from a branch**, затем **main / (root)**. Добавьте сюда ссылку из настроек Pages, когда сайт будет опубликован.
